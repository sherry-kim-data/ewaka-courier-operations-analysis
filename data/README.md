# Data (not included)

The analysis uses two Excel files provided by eWAKA for the SCU MSBA Analytics Showdown (Fall 2026):

- `boltsend_rider_history.xlsx`: one row per order offer (110,578 rows, Jan 2025 – Aug 2026)
- `boltsend_rider_perfomance.xlsx`: one row per courier per day (15,351 rows); keep the original "perfomance" spelling

They are not shared here because they belong to eWAKA. To re-run the notebook, place both files in this folder.
